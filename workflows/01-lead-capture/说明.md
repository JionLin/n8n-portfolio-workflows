# 01 Lead capture

Webhook intake for a lead form. It validates the payload, appends the lead to a Google Sheet, then sends a Slack message and an email.

Files:

- `lead-capture.json`: the main workflow (import this one).
- `error-handler.json`: an Error Trigger workflow that emails a failure alert.
- `fixtures/sample-lead-request.json`: example request body.

## Flow

1. **Lead Webhook** (`POST /webhook/lead-capture`) receives JSON.
2. **Normalize Lead** trims and lowercases fields and adds `received_at`.
3. **Email Looks Valid?** requires an `@` in the email and a non-empty name.
   - Invalid: responds `400 {"status":"rejected","reason":"name_or_email_invalid"}`.
   - Valid: continues.
4. **Append to Leads Sheet** appends a row (retries 3 times, 2 s apart).
5. **Accept Lead** responds `200 {"status":"accepted"}`.
6. **Notify Slack** and **Email Notification** each retry 3 times, 2 s apart.

## Environment variables

| Variable | Purpose |
| --- | --- |
| `LEAD_SHEET_ID` | Google Sheet ID. The tab must be named `Leads` with headers `received_at, name, email, company, message, source`. |
| `SLACK_CHANNEL` | Channel name, for example `#leads`. |
| `NOTIFY_EMAIL` | Recipient for the notification and error emails. |

## Try it

```bash
curl -X POST http://localhost:5678/webhook/lead-capture \
  -H "Content-Type: application/json" \
  -d @fixtures/sample-lead-request.json
```

## Error handling and retries

- **Webhook:** does not retry. If a node fails, n8n returns `500`, and the caller must retry.
- **Sheets, Slack, Gmail nodes:** retry 3 times with a 2-second wait. A retry after a lost response can duplicate a row or a message.
- **Error Trigger:** `error-handler.json` runs only for failed production executions, and only when it is selected in this workflow's **Settings → Error workflow**. Manual test runs do not trigger it.
- Slack and email run after the sheet append. If either fails, the row stays in the sheet and the execution is marked failed.

## Verification

Tested against a local n8n instance: invalid input returns 400, and a valid lead reaches the Sheets node. The Sheets node then fails because no Google credential is attached. Sheets, Slack and Gmail were not exercised against real accounts.
